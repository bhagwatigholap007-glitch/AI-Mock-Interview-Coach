## About the Project

AI Mock Interview Coach is a beginner-friendly web application developed using Python and Streamlit to help students and job seekers practice technical interviews.

The application allows users to select an interview role, practice role-specific questions, submit their answers, and receive basic feedback to help improve their interview preparation.

Currently, the application provides rule-based feedback. Future enhancements will include AI-powered answer evaluation, interview scoring, personalized suggestions, and voice-based interview practice.

This project was developed as a hands-on learning experience to strengthen Python programming and web application development skills.
